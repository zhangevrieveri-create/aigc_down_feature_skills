# 审计清单（量化 / 实证类论文）

## 一、公式回算（audit_metrics.py 支持）
| 指标 | 公式 | 常见错误 |
|---|---|---|
| ICIR | IC均值 ÷ IC标准差 | 均值与ICIR来自不同版本；英文展开写错 |
| Rank ICIR | Rank IC均值 ÷ Rank IC标准差 | Rank IC 与 Rank ICIR 符号相反 |
| 卡玛 | 年化收益 ÷ |最大回撤| | 某一行用了不同回撤或不同年化 |
| 年化（复利） | (1+总收益)^(365/天数) − 1 | 部分策略算术年化、部分复利；区间长度与日期不符 |
| 多空组合 | Top − Bottom | 符号写反 |
| 提升百分比 | (a/b − 1)×100；回撤缩小 = (b − a)/b×100 | 取整方向不一致（23.75% 写成 23.7%） |
| 夏普、索提诺 | 需原始日收益，无法由表内数字回算 | 至少核对 索提诺/夏普 比值是否在各行相近 |

## 二、需要人工检查的不一致模式
- 固定偏移：多行同时偏离同一个常数。
- 隐含窗口不一致：同一时间窗里各策略的"总收益→年化"隐含年数不同。
- 重复值：不同表、不同行出现完全相同的夏普等指标（可能复制错）。
- 符号矛盾：均值与比值异号。
- 极整齐的落差：消融各版本的回撤几乎相同而完整模型远小于它们（要问是不是同一次回测）。
- 叠加 vs 单独去除：消融是否叠加决定了怎么解读；叠加时边际贡献 = 相邻两行之差，不能用"相对完整模型"的差当单模块贡献。
- 正文与表：正文说"低于除X外的所有"，表里却低于包括X在内的所有；"次优""最高"与表对不上；引用不存在的表/图/指标。
